T1 Gemini Skills-Ai

About 10 minutes, once. After that, a finished CRM note takes seconds. Just follow the steps and tick them off.

On a phone? Open this page in Safari or Chrome. If you only see code, open it from the web link instead of the email or message preview. Do the actual skill setup on your computer.

Read this first (30 seconds)
  • Only use real call content once your team leader has confirmed it is approved under IXE's privacy policy.
  • Use first names or initials. Never paste phone numbers, emails, addresses, ID or bank details.
  • Always check the note against the call before it goes into Zoho. Delete any number you do not remember.

1Pick how you want to use it

2Check you have Skills

  1. Go to gemini.google.com and sign in with your work Google account.
  2. In the left menu click Customise (click More first if you can't see it).
  3. Do you see a Skills tab? Yes = carry on. No = tell your team leader, your account doesn't have Skills yet.
  1. Make sure Chrome is up to date (version 147 or newer) and restart it.
  2. Look for Ask Gemini at the top right of Chrome and click it.
  3. Type / in the box. Do you see Add Skill +? Yes = carry on. No = type chrome://flags in the address bar, search "Skills", set it to Enabled, relaunch Chrome. Still nothing? Tell your team leader.

3Add your skills, one at a time

Do the coloured boxes below in order. Tick "Done" on each one.

4Use it, every time

  1. Open gemini.google.com and click New chat (one chat per client).
  2. Type / and pick the skill from the list.
  3. Paste the transcript under it. Swap full names for first names or initials first.
  4. Press send. Click the copy icon on the grey box and paste it into Zoho.
  1. Open the page with the transcript (or have it ready to paste).
  2. Click Ask Gemini, type / and pick the skill.
  3. If the transcript is not on the page, paste it under the command. Press Enter.
  4. Copy the note into Zoho. If the layout looks wrong on a long transcript, run it on the Gemini web page instead.

5If something goes wrong

The skill doesn't show when I type /
Web: Customise, Skills, open it and make sure it is Activated (More, then Activate). Start a new chat. Chrome: check chrome://skills/yourSkills.
The note is in the wrong layout
Start a new chat and run it again. Add "Use the skill's format exactly" under the command. In the Chrome sidebar, use the web page instead.
A number appears that wasn't in the call
Delete it and write "not disclosed". Re-run with "Do not guess any figures."
Upload was rejected (web)
Use the Chrome sidebar method for that skill, or ask your team leader.
I want to change a skill
Web: Customise, Skills, open it, edit the instructions, save. Chrome: chrome://skills/yourSkills, then Edit.
